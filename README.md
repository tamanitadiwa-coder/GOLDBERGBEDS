# Goldberg Beds

Shop website for Goldberg Beds — loft beds, bunk beds, kids' beds and storage, built to order. Orders go to WhatsApp (+27 78 067 9984).

- `index.html`, `products.js`, `img/` — the site (GitHub Pages serves this from the repo root)
- `backend/` — PocketBase migration and setup guide for products and orders
